# Lotwise — Dealership Inventory Desk

Full-stack car dealership inventory system built test-first (TypeScript, React, Express, PostgreSQL).

> Work in progress — Phase 0 (walking skeleton). See [`docs/sdlc-execution-plan.md`](docs/sdlc-execution-plan.md) and [`docs/api-contract.md`](docs/api-contract.md).

## Prerequisites

- Node.js 22+ and npm
- Docker (for local PostgreSQL)

## Setup

```bash
cp .env.example .env
docker compose up -d db
```

More commands are added here as each part of the skeleton lands.
